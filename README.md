### ⚡ Foco Técnico

</div>

- 🛠️ **Frontend:** Interfaces reativas e tipadas com **React**, **Vue**, **Svelte** e **Solid**.
- 🚀 **Backend:** APIs, gateways e proxies de alta performance com **Bun**, **Node.js** e **TypeScript** — streaming, tool calling e sessões persistentes.
- 🐋 **Deploy & CI/CD:** Conteinerização com **Docker**, ambientes **Linux** e pipelines de **CI** com typecheck e testes automatizados.
